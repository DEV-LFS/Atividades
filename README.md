# 📚 Atividades de Programação

Repositório dedicado à prática de **lógica de programação** e ao desenvolvimento de fundamentos em **Python**.

O objetivo deste projeto é centralizar exercícios, atividades acadêmicas e desafios práticos, mantendo uma organização simples que permita acompanhar a evolução dos estudos ao longo do tempo.

## 🎯 Objetivos

Este repositório é utilizado para praticar e consolidar conceitos como:

- entrada e saída de dados;
- variáveis e tipos de dados;
- operadores aritméticos e relacionais;
- estruturas condicionais;
- estruturas de repetição;
- vetores e matrizes;
- funções e procedimentos;
- validação de dados;
- decomposição de problemas;
- raciocínio lógico e construção de algoritmos.
