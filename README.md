## 📖 Sobre o repositório

Este repositório reúne **atividades acadêmicas, exercícios de lógica de programação e soluções desenvolvidas em Python**.

## 🐍 Atividade — Funções e Módulos em Python

A atividade mais recente trabalha **funções, parâmetros, retorno de valores, escopo de variáveis e o módulo `math`**.

| Exercício | Arquivo | Conteúdo |
|---:|---|---|
| **01** | [`exe_01.py`](./atividades_28/09/2026/exe_01.py) | `math.sqrt()`, `math.ceil()` e `math.floor()` |
| **02** | [`exe_02.py`](./atividades_28/09/exe_02.py) | Função para cálculo da área de um círculo com `math.pi` |
| **03** | [`exe_03.py`](./atividades_28/09/exe_03.py) | Parâmetros, condicionais e maior entre três valores |
| **04** | [`exe_04.py`](./atividades_28/09/exe_04.py) | Escopo local e escopo global |
| **05** | [`exe_05.py`](./atividades_28/09/exe_05.py) | Função para cálculo da hipotenusa com o Teorema de Pitágoras |

### Conceitos aplicados

```text
import
  ↓
definição de funções
  ↓
parâmetros
  ↓
processamento
  ↓
return
  ↓
chamada da função
  ↓
exibição do resultado
```

Também são utilizados:

- `input()` para entrada de dados;
- `int()` e `float()` para conversão de tipos;
- `if`, `elif` e `else` para tomada de decisão;
- f-strings para formatação de saída;
- `**` para potenciação;
- `:.2f` para formatação de números decimais;
- funções e constantes do módulo `math`.

## ▶️ Como executar

### 1. Clone o repositório

```bash
git clone https://github.com/DEV-LFS/Atividades.git
```

### 2. Acesse a pasta

```bash
cd Atividades
```

### 3. Execute um arquivo Python

```bash
python atividade_01.py
```

Em ambientes que utilizam o comando `python3`:

```bash
python3 atividade_01.py
```

### Exemplo — atividade de funções e módulos

```bash
python atividades_28/09/exe_05.py
```
