## 📖 Sobre o repositório

Este repositório reúne **atividades acadêmicas, exercícios de lógica de programação e soluções desenvolvidas em Python**.

A proposta é manter os estudos organizados por atividade e por data, facilitando a consulta dos códigos e o acompanhamento da evolução em **Algoritmos e Programação**.

> 💡 O repositório funciona como um registro prático dos conteúdos desenvolvidos durante os estudos de Ciência da Computação.
