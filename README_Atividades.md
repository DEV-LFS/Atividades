# 📚 Atividades de Programação

Repositório dedicado à prática de **lógica de programação** e ao desenvolvimento de fundamentos em **Python**.

O objetivo deste projeto é centralizar exercícios, atividades acadêmicas e desafios práticos, mantendo uma organização simples que permita acompanhar a evolução dos estudos ao longo do tempo.

# 🧠 100 Exercícios de Lógica de Programação

A pasta [`PDF100`](./PDF100) reúne uma coleção estruturada de exercícios resolvidos em **Python 3**.

Os exercícios foram organizados por nível e por assunto:

| Módulo | Exercícios | Conteúdo |
|---|---:|---|
| **01 — Primeiros Algoritmos** | 01–15 | Entrada, saída, variáveis, cálculos e operadores |
| **02 — Estruturas Condicionais** | 16–35 | `if`, `elif`, `else`, comparações e intervalos |
| **03 — Estruturas de Repetição** | 36–60 | `for`, `while`, contadores, acumuladores e validações |
| **04 — Vetores e Matrizes** | 61–80 | Listas, índices, buscas, filtros, ordenação e matrizes |
| **05 — Funções e Desafios** | 81–100 | Funções, reutilização de código e problemas combinados |

Cada solução possui seu próprio arquivo `.py`.

O arquivo [`PDF100/README.md`](./PDF100/README.md) contém a explicação individual de cada exercício, incluindo objetivo, lógica utilizada e pontos importantes da implementação.

### ⚠️ Exercícios 11, 12 e 13

O material utilizado como base não apresenta os enunciados dos exercícios **11, 12 e 13**.

Por esse motivo, eles foram mantidos apenas como arquivos de aviso, evitando a criação de requisitos que não estavam presentes no material original.

## ▶️ Como executar

### 1. Clone o repositório

```bash
git clone https://github.com/DEV-LFS/Atividades.git
```

### 2. Entre na pasta

```bash
cd Atividades
```

### 3. Execute uma atividade

```bash
python atividade_01.py
```

Ou, dependendo da configuração do sistema:

```bash
python3 atividade_01.py
```

### Executando os exercícios do `PDF100`

```bash
cd PDF100/solucoes
python ex001_soma_de_dois_numeros.py
```

## 📈 Progressão dos exercícios

A sequência `PDF100` foi estruturada para aumentar gradualmente a complexidade.

```text
Entrada e saída
      ↓
Operações matemáticas
      ↓
Estruturas condicionais
      ↓
Estruturas de repetição
      ↓
Vetores e matrizes
      ↓
Funções
      ↓
Problemas combinados
```

Essa progressão permite trabalhar não apenas a sintaxe de Python, mas principalmente a capacidade de transformar um problema em um algoritmo.

## 📌 Organização dos arquivos

Os exercícios da pasta `PDF100/solucoes` seguem o padrão:

```text
exNNN_nome_do_exercicio.py
```

Exemplos:

```text
ex001_soma_de_dois_numeros.py
ex017_par_ou_impar.py
ex045_sequencia_de_fibonacci.py
ex081_funcao_para_somar.py
ex100_desafio_final_-_analise_de_uma_turma.py
```

Esse padrão facilita a navegação e mantém a ordem original dos exercícios.
